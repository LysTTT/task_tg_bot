# TaskBot

TaskBot — русскоязычный Telegram-бот для личных задач, сроков и напоминаний.
Напишите в личном чате «Надо купить хлеб 18 декабря в 6 вечера».
Бот выделит действие, покажет срок в вашем часовом поясе и предложит сохранить задачу.

## Возможности

- Разбор обычного и пересланного текста с помощью Google Gemini. Поддерживаются задачи со сроком и без срока.
- Голосовой ввод до 60 секунд и 5 МБ. Запись отправляется в Gemini после подтверждения в Telegram.
- Карточки задач, смена статуса, изменение срока, списки и поиск по названию.
- Напоминания за сутки, час, полчаса и в момент срока. Утренний и вечерний отчёты по местному времени.
- Настройки профиля, согласие с действующей версией документов и удаление профиля с задачами.

## Быстрый старт

Понадобятся Python 3.14, Docker с Compose, токен Telegram-бота от BotFather и ключ Gemini API.

1. В корне репозитория скопируйте `.env.example` в `.env`. Задайте пароль PostgreSQL, `BOT_TOKEN` и `GEMINI_API_KEY`. Полный список настроек приведён ниже.
2. Запустите PostgreSQL и примените миграции. Команды для PowerShell:

   ```powershell
   docker compose up -d --wait postgres
   python -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m alembic upgrade head
   ```

   В Linux и macOS используйте `.venv/bin/python` для команд из виртуального окружения.

3. [Опубликуйте действующую версию соглашения](#публикация-соглашения).
4. Запустите `.\.venv\Scripts\python.exe -m bot.main`, затем отправьте боту `/start` и примите соглашение.

### Настройки

| Переменная | Назначение |
| --- | --- |
| `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` | Пользователь, пароль и имя базы |
| `POSTGRES_PORT` | Локальный порт PostgreSQL, по умолчанию `5432` |
| `POSTGRES_HOST` | Адрес PostgreSQL, по умолчанию `127.0.0.1`. В контейнере используется `postgres` |
| `BOT_TOKEN` | Токен Telegram-бота |
| `GEMINI_API_KEY` | Ключ для разбора текста и голосовых сообщений |
| `GEMINI_MODEL` | Модель Gemini, по умолчанию `gemini-3-flash-preview` |

Храните ключи в локальном `.env`. В репозиторий добавляйте шаблон `.env.example`.
В базовой конфигурации Compose также описан Redis для будущего хранения состояний.

### Публикация соглашения

После миграций откройте `psql` командой `docker compose exec postgres psql -U taskbot -d taskbot`.
Подставьте свои имя пользователя и имя базы, если изменили их в `.env`.
Выполните SQL, заменив URL на опубликованные документы проекта.

```sql
BEGIN;
UPDATE terms_versions SET is_current = false WHERE is_current;
INSERT INTO terms_versions (version, url_terms, url_privacy, is_current)
VALUES ('1.0', 'https://example.org/terms', 'https://example.org/privacy', true);
COMMIT;
```

Используйте новый номер версии при каждой публикации. Перед запуском для реальных пользователей укажите в политике обработки данных, что свободный текст и подтверждённые голосовые отправляются в Google Gemini.

### Запуск в Docker

```sh
docker compose -f compose.yaml -f compose.bot.yaml up --build -d bot
docker compose -f compose.yaml -f compose.bot.yaml logs -f bot
```

При старте контейнер применяет миграции. Для новой базы опубликуйте соглашение после запуска.
На один Telegram-токен запускайте один экземпляр бота в режиме polling.
Если Compose Bake не запускается, соберите образ через `docker build -t taskbot-local .`, затем запустите сервис с флагом `--no-build`.

## Как пользоваться

1. Вызовите `/start`, примите соглашение и при необходимости задайте часовой пояс, например `/timezone Europe/Moscow`. У нового профиля используется UTC.
2. Отправьте «Купить хлеб» или «Купить хлеб 18 декабря в 6 вечера». В карточке появится «без срока» или дата в формате `ДД.ММ.ГГГГ ЧЧ:ММ`.
3. Проверьте черновик и нажмите «Сохранить». Gemini учитывает местное время профиля. Если указана только дата, бот предлагает срок 23:59. Если срок неоднозначен, бот просит повторить задачу с датой и временем.
4. Откройте `/today`, `/tomorrow`, `/week`, `/overdue`, `/completed` или `/all`. Списки принимают номер страницы, например `/all 2`.

| Команда | Действие |
| --- | --- |
| `/help` | Справка |
| `/task 12` | Карточка задачи |
| `/deadline 12 2026-12-18 18:00`, `/deadline 12 off` | Установить или убрать срок |
| `/search купить хлеб` | Поиск по названию |
| `/settings`, `/timezone Europe/Moscow` | Просмотр настроек и изменение часового пояса |
| `/morning 09:00`, `/evening 19:30` | Время ежедневных отчётов |
| `/terms`, `/consent`, `/delete_me` | Документы, сведения о согласии, удаление профиля |

Черновик хранится в памяти 15 минут. Новая распознанная задача или голосовое для разбора заменяет предыдущий черновик.
Бот проверяет расписание каждые 30 секунд и догоняет отправки в пределах 30 минут. Отметки доставок хранятся в PostgreSQL. При сбое после отправки сообщения и до фиксации отметки возможен дубль.

## Разработка

Стек проекта включает aiogram 3, SQLAlchemy с asyncpg, PostgreSQL, Alembic и Gemini API.

- `bot/` — маршруты Telegram, карточки и фоновая отправка уведомлений.
- `core/` — настройки, модели и сервисы.
- `migrations/` — миграции PostgreSQL.
- `tests/` — проверки приложения и базы данных.
- `docs/` — [состояние проекта](docs/PROJECT_STATUS.txt) и [учебная дорожная карта](docs/ROADMAP.md).

Тесты используют отдельную схему PostgreSQL внутри откатываемой транзакции.
Поднимите PostgreSQL и укажите в `.env` реквизиты пользователя с правом создания схем.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```
